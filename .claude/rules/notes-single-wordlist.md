# Notes: one single word list

When adding vocabulary to the hoofdstuk notes files:

- Keep ALL new words in the single table under "1. Nieuwe woorden (Woordenlijst)".
- Do NOT create separate sub-lists or sub-tables (e.g. "Internationale woorden", per-section/dialogue headings). Merge such words into the main table with the same columns (Woord | Betekenis | Voorbeeldzin | Pag.).
- If a word has no example sentence in the book, put `–` in the Voorbeeldzin column.
